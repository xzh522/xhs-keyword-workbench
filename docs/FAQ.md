# 常见问题

## GitHub 链接就是在线网站吗？

不是。本项目采用本地运行方案：GitHub 提供源码和下载。每位访客在自己的电脑启动后端，浏览器界面才能工作。无需租服务器，但依赖下载和小红书检索仍需网络。

## 是否需要 ChatGPT、Codex、小红书 API 或大模型密钥？

不需要。词库模式只需 Python；真实检索需要 Edge、Playwright、独立 Socai CLI 和你自己的小红书扫码登录。关键词建议使用词库与规则，不是联网大模型。

## 为什么必须装 CLI，桌面 Socai 不行？

后端需要调用 `version --no-check --json` 和 `xhs get-notes` 取得结构化结果。桌面程序可能同名，但不一定提供命令行格式。环境检查会拒绝安装包或不兼容版本。

## 是否保证不会触发平台限制？

不保证。登录、网络、页面变化、验证和限流都可能阻止检索。工具不会绕过限制，不自动处理验证码，不换账号或代理；已采集的部分样本会明确标注。

## 为什么扫码后要点“开始拓词”？

登录和提交研究是两步。工具需核验已登录后才提供开始按钮，避免在你还未选完条件时自动采样。

## 排名是小红书全平台 TOP10 吗？

不是。只是本轮已取得、原始发布日期有效且匹配主题的笔记样本，按去重样本量排序。没有可核验样本就不能计算真实样本排名，更不能推算平台搜索量。

## 公开示例词库与原客户版本有什么不同？

核心研究流程保留，词库改为独立手写的小型航空与旅行示例，移除了客户原始 Excel、项目词包、品牌 Logo、研究历史与登录资料。公开品牌词用于研究示例，不表示客户授权。

## 历史在哪里？

只保存在你解压目录的 `data/`。不同浏览器身份隔离，更新时先自行备份。仓库和打包器不会上传这些文件。清除浏览器 Cookie 可能导致原身份历史不再在当前浏览器可见，但不代表自动删除本地数据库。

## 可以把日志和 data 发到 GitHub Issues 吗？

不要。只提供去掉个人路径与账号信息后的错误文字和环境版本。不要公开登录二维码、Cookie、密钥、完整日志、历史数据库或设置文件。
