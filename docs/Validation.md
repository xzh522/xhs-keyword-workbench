# 验证边界与真机验收

## 边界

本仓库提供可复现的离线测试，不在 CI 中登录小红书。测试中的固定笔记标识和正文只用于软件验证，不是采集成果或真实热门笔记。

Mac 开发环境可验证本机服务、示例词库、导入、历史、身份隔离、导出与依赖检查。公开版尚未重新完成真实小红书扫码/检索验收；原有私有版本的登录状态和研究结果不会迁入。

Windows 10/11 x64：已有平台适配、启动入口及自有 Job Object 进程清理测试，但**尚未完成 Windows 真机扫码和真实小红书检索验收**。即便 Windows Actions 的确定性测试通过，也只能确认所执行的离线路径。

## 每个平台的人工验收

- [ ] 记录系统、Python、Edge、Socai CLI 和源码版本。
- [ ] 在含中文和空格的可写目录解压，运行词库模式，产生至少5词，导出 CSV 并检查中文。
- [ ] 重启后可查看自己的历史；另一个普通浏览器身份看不到该历史。
- [ ] 运行环境检查通过；在线模式新建独立 Edge，不复用日常浏览器资料。
- [ ] 在工具页本人扫码、手机确认，明确看到“已连接”；二维码消失不算登录成功。
- [ ] 手动提交一轮检索，核验正确主题、真实来源、原始发布日期和过去30天窗口。
- [ ] 对照原文核对计数与至少5个相关关键词；未知互动不变为0。
- [ ] 取消和断开只结束工具自己的进程，不影响日常 Edge 或其他 Socai。
- [ ] 断开再连接必须新扫码；退出后不残留自有浏览器或 Socai。
- [ ] 重复启动提示端口占用，不杀掉原有服务。
- [ ] 遇到验证/限流时立即停止，不将软件错误或无数据当作零热度。

平台验证导致无法完成时记录实际限制，不把受阻操作写成验收成功。求助截图必须遮盖账号、二维码和个人信息。
