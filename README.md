# 小红书关键词研究工具

把主题、词类和可选目的地，转成可追溯的关键词研究表。为航空与旅行场景设计，包含品牌词、竞品词、水上运动、亲子游、留学、转机等 13 类公开示例。

**这是下载到自己电脑运行的工具，不是点击即用的在线网站。无需 ChatGPT 账号或云服务器。**首次使用需要安装 Python；真实检索还需要 Edge、Playwright 和 Socai CLI，并由你本人扫码授权。

> Windows 10/11 x64 为实验支持：代码包含 Windows 适配与测试，但尚未完成 Windows 真机小红书扫码和实际检索验收。确定性测试通过不等于真实平台检索通过。

## 下载与快速开始

[下载当前源码 ZIP](https://github.com/xzh522/xhs-keyword-workbench/archive/refs/heads/main.zip) · [Mac 安装说明](docs/Mac.md) · [Windows 安装说明](docs/Windows.md) · [常见问题](docs/FAQ.md)

下载后**先完整解压**。不要直接在 ZIP 中运行，也不要只下载 `index.html`。如果从源码 ZIP 下载，两种系统入口都在同一个文件夹里。

| 想体验什么 | Mac | Windows |
|---|---|---|
| 先体验关键词生成、导入分析、历史和导出 | 安装 Python 3.10+，双击 `启动工作台.command` | 安装 Python 3.10+，双击 `Windows_启动词包模式.cmd` |
| 安装网页组件 | 双击 `安装网页组件.command` | 双击 `Windows_安装网页组件.cmd` |
| 检查在线依赖 | 双击 `检查运行环境.command` | 双击 `Windows_检查运行环境.cmd` |
| 扫码真实检索 | 依赖齐备后双击 `启动本机扫码版.command` | 依赖齐备后双击 `Windows_启动拓词工具.cmd` |

启动后自动打开 `http://127.0.0.1:8769`。保留启动窗口；关闭窗口、重启或电脑休眠会影响本机服务。该地址指向你自己的电脑，不能作为公网网址分享。

## 操作流程

1. 选择项目与词类，按需填写细分主题和目的地区域。品牌词、竞品词可不填地区。
2. 选择参考模式：
   - **基于示例词库拓展**：即时生成候选关键词，不读取小红书，也不产生实时热度。
   - **导入小红书笔记分析**：读取你有权使用的 CSV/JSON，统计有效样本。
   - **在线检索小红书**：先勾选本人授权，在页面内扫码并在手机确认，显示“已连接”后点击“开始拓词”。
3. 查看研究方向、至少5个相关关键词、样本量和来源，再导出 CSV。查询条件和结果一起保存在本地历史中。

词库模式可以先熟悉界面，但**不等同于在线检索验收**。没有登录、遭遇验证或限流时，工具不会把离线建议伪装成采集结果。

## 能做什么

- 左右独立滚动的工作台；可选目的地；品牌/竞品可不限定地区。
- 小红书普通网页搜索与 Socai 正文读取，不调用小红书私有 API。
- 北京时间截至昨日的过去30个完整自然日；核对原始发布日期、去重、保留来源。
- 按本次有效匹配笔记样本量排序，缺失互动数不当作0。
- 每个方向至少5个相关关键词，区分原词库、笔记出现与规则拓展建议。
- 本地历史、备份和适合 Excel 打开的 UTF-8 CSV。
- 取消检索、超时和部分样本提示；出现安全验证、登录失效或限流时停止。

## 数据口径与限制

**笔记样本量不是搜索量，也不是曝光量、平台总笔记数或小红书官方热度。**样本相对指数只用于比较本轮样本，不是平台指数。不同账号、默认排序和检索时间可能产生不同结果。

只统计可核验原始发布日期的笔记。仅有编辑日期、日期不明或来源不完整的记录会被排除。采样不完整时保留明确标注的部分样本，不给完整排名与指数。

关键词生成基于示例词库、相关笔记话题和搜索意图规则，**不是调用联网大模型，也不能证明每个建议词都被真实用户搜索过**。广告投放前需人工审核。

目的地是沿用带版本与公开来源的航空目的地保守示例清单，并非实时或完整航点目录；实际航线、航班、价格、政策请查航空公司官网。

## 隐私与安全

- 只在本机监听，使用独立临时 Edge 配置，不读取你日常 Edge 的个人配置。
- 小红书登录需要你本人明确授权；会话用于本机独立浏览器，不是把账号交给项目作者。
- 断开、闲置30分钟或服务重启会清理本会话。请使用自己的可信电脑；系统管理员仍可能接触本机进程。
- 历史保存在本目录 `data/`，按浏览器身份区分，不会上传到 GitHub。**发布或求助时不要发送 data、Cookie、二维码、settings.local.json 或日志原文。**
- 本仓库不含客户原始词包、Logo、客户研究记录、登录态或第三方程序二进制。示例中的公开品牌名不表示合作、授权或背书。
- Socai 不是免风控承诺。遇到平台限制，按官方方式处理；工具不绕过验证、不换账号重试或伪装流量。

## 运行环境

- Python 3.10 或更新版本，标准库负责本机后端、SQLite 和词库模式。
- 在线模式需要 Microsoft Edge、`requirements-web.txt` 中的 Playwright，以及独立 Socai CLI。
- 适配器目前接受 Socai CLI 0.6.0 / 0.6.6，并检查只读命令格式；Windows 要求0.6.6。**不要直接换成最新版并假定兼容。**安装方式见系统文档。
- 本项目直接调用 CLI，`socai-social-research` 是设计参考的研究流程；访客不需要安装 Codex、ChatGPT 或 Agent Skill。

## 项目结构

```text
index.html                 工作台界面
launcher.py                本机启动、安装组件、依赖检查
server.py                  本机 HTTP 与按浏览器身份隔离的历史
engine.py                  词类匹配、关键词建议、样本统计
ordinary_search.py         普通网页搜索适配
socai_runtime.py            只读 CLI、限时、取消与自有进程清理
publication_verifier.py     原始发布日期核验
catalog.json               独立编写的公开示例词库
scripts/package_public.py  白名单打包；不收集本地私有数据
tests/                     不登录社交账号的确定性测试
```

## 开发与验证

以下开发命令仅适用于完整源码 ZIP（仓库的 Code → Download ZIP），不是按系统精简的体验包。源码中同时包含 tests 和两系统启动文件。在源码解压目录运行：

```bash
python -m unittest discover -s tests -v
python scripts/package_public.py --output dist
```

Mac 上的命令名可能是 `python3`。打包后得到 Mac、Windows ZIP 和 `SHA256SUMS.txt`；包中不带 Python、Edge 或 Socai。GitHub Actions 仅验证确定性功能和进程管理，不登录小红书、不执行真实采样。

真实检索必须另做人工验收，步骤见 [验证状态与清单](docs/Validation.md)。不要仅根据测试数或 CI 绿灯宣称 Windows 小红书检索已跑通。
